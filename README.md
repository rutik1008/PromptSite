# PromptSite

An AI-first website builder. Describe the site you want, refine the result, preview it, export the code and deploy to Vercel.

## Run locally

```bash
npm install
npm run dev
```

The starter runs without keys using polished demo generation. Connect your preferred generation service in `src/main.jsx` where noted before production. For Vercel, the app already produces a portable HTML export and directs the user to Vercel's import flow.
